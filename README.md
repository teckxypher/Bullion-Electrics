# Bullion Electrix — Glass UI Electrical Engineering Website

A responsive, multi-page front-end website inspired by the supplied reference layout:
- Dark architectural/electrical aesthetic
- Transparent glass cards
- Neon orange glass buttons
- Left-opening side navigation
- JavaScript-powered dark/light mode
- Skeleton-style page loader on every page
- 20 independent HTML pages
- LocalStorage contact, booking, career and admin demo
- Admin dashboard for viewing locally stored requests and publishing local service cards
- No backend required for the demo
